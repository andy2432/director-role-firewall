# Security

Do not report secrets, credentials, production data, or private chat histories in
public issues.

The firewall is a guardrail, not a sandbox. Report bypasses involving:

- uncaptured tool paths;
- fabricated dispatch or evidence receipts;
- duplicate active directors;
- superseded directors becoming workers;
- state-file tampering;
- hook configuration trust;
- command normalization or shell escaping.

Include the platform, adapter, role contract revision, request JSON, expected
decision, actual decision, and minimal reproduction without sensitive data.
